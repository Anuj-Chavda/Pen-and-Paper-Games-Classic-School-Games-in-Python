# ✏️ Pen & Paper Games

> **Games we played with nothing but a pen, paper, and a little too much free time. 📒**

A nostalgic collection of classic **pen-and-paper, notebook, school, and two-player games**, recreated in Python.

The goal is simple:

**Take the games we used to play on the last page of our notebooks and bring them to the computer — while keeping their simple, local, nostalgic feeling.**

## 🎮 What is this?

This repository contains a growing collection of classic games that can be played by **two people on the same computer**, completely offline.

No accounts.
No servers.
No internet connection.
Just two players and a game.

## 🐍 Built with Python

The project prioritizes Python's **standard library** wherever possible.

For graphical games, it mainly uses well-established libraries such as:

* **Tkinter** — lightweight GUI and board games
* **Pygame** — games requiring animation, sound, or richer 2D graphics

The project intentionally avoids unnecessary dependencies and complicated frameworks.

## 🎯 Project Philosophy

The project follows a few simple principles:

* **Offline first**
* **Two players**
* **Simple controls**
* **Easy to understand**
* **Easy to run**
* **Minimal dependencies**
* **Open source**
* **Nostalgic rather than over-engineered**

## 🚀 Running a Game

Clone the repository and run the game you want:

```bash
git clone <repository-url>
cd pen-paper-games
python games/dots-and-boxes/main.py
```

Individual games contain their own instructions where necessary.
